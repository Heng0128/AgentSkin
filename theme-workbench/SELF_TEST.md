# AgentSkin 工作室 · 本地自测清单

> 沙箱环境无法启动真实 agent + CDP，以下为开发者在本机 `npm start` 后的手测步骤。
> 目标：确认「真实 DOM 回放 + 工具箱微调 + 渐变强调背景 + 导出主题」整条链路可用。

## 0. 启动与前置
- `npm install` 后 `npm start`（开发模式，热重载）。
- 打开「主题工作室」页（Studio 独立窗口）。
- 任选一个已接入的 agent（traework / qoderwork / workbuddy / doubao / codex），确认其调试端口已暴露（控制台无 "No debug port" 报错）。

## 1. 工程与快照
- [ ] 新建工程：填名称/作者/agent，确认进入空工程态。
- [ ] 抓取当前渲染（CDP）：点击快照，右侧出现「真实界面预览 · Agent DOM 回放」且布局接近真实 agent。
- [ ] 抓取原生界面（无主题）：点「获取原生」，切到 baseline 视图对比，确认是去主题后的原貌。
- [ ] 关闭窗口再打开：确认 `theme-workbench/projects/<id>/snapshot.json` + `baseline.json` 已落盘、可重载。

## 2. 工具箱微调（design 视图）
逐项开关，确认预览实时变化：
- [ ] 配色：强调色 / 背景色 / 文字色 / 表面色（取色器 + 十六进制输入）。
- [ ] 渐变强调背景（新增）：开启后主背景出现「强调色→背景色」斜向渐变铺底；关闭即恢复纯色。
- [ ] 形状与边框：圆角 / 内边距 / 阴影等级 / 模糊 / 边框粗细 / 显示分隔线。
- [ ] 字体：字号 / 字族 / 行高。
- [ ] 动效：时长 / 缓动。
- [ ] 仅预览项（不烘焙）：内容缩放 / 明暗反转 / 对比度 / 饱和度。
- [ ] 底部「N 项微调生效」徽章计数随改动增减；「重置」清空所有 override。

## 3. 导出主题
- [ ] 设好若干微调（含渐变强调背景）→ 点导出，填名称/作者。
- [ ] 确认产物落在 `theme-workbench/out/<slug>/`：`manifest.json` + `preview.png` + `icon.png` + `assets/css/<agentId>.css`。
- [ ] 打开导出 CSS，确认：
  - 调色板 `--agentskin-*` 已写入 `:root`；
  - 工具箱维度（圆角/间距/阴影/模糊/字体/配色/边框/行高）已烘焙为 `!important` 规则；
  - 渐变强调背景已生成 `background-image: linear-gradient(...)`（含 `--as-grad` 变量）。
- [ ] 把导出的 `.agentskin-theme` 目录作为工程导入，确认可被主题中心识别。

## 4. 边界与已知限制
- 预览为**静态回放**（不可交互），仅反映抓取瞬间的 DOM。
- 复杂 agent 节点上限 `MAX_NODES=2500`，超出部分会被截断。
- 视频 / canvas / 未内联的外部资源在沙箱预览中留白（真实 agent 中正常）。
- 明暗反转 / 对比度 / 饱和度 / 内容缩放**仅作用于预览**，不会进入导出主题。
