# AgentSkin Desktop — 产品定位（活文档）

最后更新：2026-08-07。与代码同步维护；与代码冲突时以代码为准。

## 一句话定位

**面向无原生定制能力 AI 应用的跨 Agent 视觉环境配置器**：为 Electron AI 应用注入主题与动态壁纸，创造完整的 AI 工作环境，而不是简单换肤。

## 产品公式

```
Agent（目标应用）
  + Theme Runtime        主题运行时
  + Wallpaper Runtime    壁纸运行时
  + Environment Bundle   环境组合包
  = 完整的 AI 工作环境
```

四个支柱均已有代码实体；"环境"的一等公民语义（主题+壁纸一键组合应用/恢复）是当前正在补的最后一块。

## 我们是什么、不是什么

| 是 | 不是 |
|----|------|
| 目标应用之外的独立运行时 | IDE 插件（不寄生在宿主内） |
| 视觉环境配置器（主题+壁纸） | AI 编排工具 / 监控平台 / Agent 市场 |
| 寄生于成熟内容生态（Wallpaper Engine） | 自建内容平台（当前阶段） |

## 目标用户与目标应用

目标应用必须同时满足两个条件：**用户基数大** + **无原生主题能力**。

- 当前六个目标：豆包、ChatGPT 桌面版、TRAE SOLO CN、QoderWork CN、WorkBuddy、ZCode。
- 头部双目标：豆包、ChatGPT 桌面版——投入权重向其倾斜。
- Cursor / VS Code 系工具自带主题体系，明确不服务。
- 不追求"万物自动适配"：通用应用自动发现引擎已否决立项。

## 护城河

1. **多 Agent CDP 注入引擎**：发现→连接→分层注入→持久化→自愈→验证的完整链路，含每个目标应用的适配知识。唯一真正难复制的资产。投资方向是可靠性，不是新能力。
2. **Scene PKG 解析能力**：Wallpaper Engine 创意工坊中大量优质壁纸是 Scene 场景包；完整解析 TEX 纹理 / LZ4 / 粒子并渲染注入目标应用，是别人短期抄不走的差异化能力。
3. **主题包标准 + 生成管线 + 契约门禁**：生态的地基。

## 投资边界

### 持续投资

- 注入可靠性（自愈、升级适配、失败诊断）
- 内置主题与配色方案的内容供给
- 环境组合的应用/恢复体验（bundle、环境预设）
- 头部双目标（豆包、ChatGPT 桌面版）的深度适配
- Scene 解析的补完（更多 Scene 特性支持）

### 冻结 / 不做

- 新增小基数适配器
- 自建内容 CDN、账号系统、服务端（Marketplace 平台化）
- 重构注入架构
- 新增 UI 页面（现有六页封顶）
- 一次性提案文档（需求直接进 ROADMAP 执行）

## 内容供给现状与目标

内置主题当前 15 个。管线能力远超内容供给——近期优先级是内容生产而非管线建设。

## 已知风险

| 风险 | 对策 |
|------|------|
| 目标应用封禁远程调试端口 | 多目标分散；快速适配新目标；篮子要少而大 |
| 目标应用原生支持定制 | 持续覆盖新出现的"无定制能力"应用 |
| 内容饥荒 | 主题内容生产排第一优先级 |
| 第三方主题/壁纸的安全风险（参考 WE 应用类壁纸恶意软件事件） | Scene 只做解析渲染不执行；主题包 lint + schema 硬校验；未来分发需签名机制 |
