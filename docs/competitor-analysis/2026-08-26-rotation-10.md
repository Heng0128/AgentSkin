## 2. 核心发现与行业趋势

### 趋势 1：终端调色板到主题格式的自动转换
`lafllamme/codex-themes` 是首个将 `.itermcolors` 等终端调色板自动转换为 Codex 兼容 JSON 预设的 TypeScript 工具包：
- 基于 mbadolato/iTerm2-Color-Schemes（400+ 终端主题）
- 自动转换为 Codex 主题 JSON 格式
- 提供 normalize/rescore 后处理流程
- 含可浏览站点生成

### 趋势 2：跨平台换肤引擎的成熟化
`xnydl/codex-dream-skin`（54 stars，本轮最高星）展示了成熟的跨平台换肤架构：
- v2.0 自适应全窗引擎（基于上游 Studio 1.2.0）
- 整窗真背景（16:9 壁纸连续铺满）
- 本地 Canvas 自动分析亮度/主色/焦点/安全区
- 亮暗自动（appearance: auto 跟随系统）
- macOS 菜单栏（SwiftBar）+ Windows 系统托盘热切换
- 6 套程序化生成预设（无第三方 IP）

### 趋势 3：WorkBuddy 注入的持久化方案
`itcastWsy/workbuddy-skin` 创新性地提出 `enable-cdp` 持久化环境变量方案：
- 首次启动时通过环境变量或快捷方式注入调试端口
- 之后每次开机换肤不再需要重启 WorkBuddy
- 跨平台单 exe 绿色免安装（内置全部主题资源）
- 注入器零依赖（仅 jimp 用于壁纸压缩）
- DOM 勘察器辅助选择器校正

### 趋势 4：Agent Skill 驱动的自安装换肤
`zhangxiaoqiang1991/workbuddy-skin-skill` 是 CodeDrobe Core 的 WorkBuddy 场景扩展：
- 用户直接在 WorkBuddy 里说"给我换肤"
- 支持上传图片 + 联网风格研究
- 10 套内置 Skin（全部通过自动对比度检查）
- 6 套深色 Skin 额外覆盖任务正文/表格/卡片
- 失败时自动恢复原生界面

### 趋势 5：动态粒子特效 + 桌面启动器
`syiibfs-hash/ritual-ink-codex-theme-launcher` 实现了一套完整的 Windows 桌面换肤启动器：
- 26 个 CSS 粒子（仅 transform + opacity 动画，无 Canvas）
- 尊重"减少动态效果"系统设置
- 个性化图标（桌面快捷方式 + 任务栏缩略图）
- 隐藏启动器（不显示 PowerShell/Node/托盘）
- 宠物兼容（自动跳过透明悬浮窗）

## 5. 推荐执行方案

### 方案 A：持久化调试端口管理器（P0）

**目标**：实现 `enable-cdp` 持久化环境变量方案，减少 WorkBuddy/Codex 重启次数。

**实现路径**：
1. 新增 `src/main/services/persistent-cdp-manager.ts`
2. 检测应用快捷方式是否包含 `--remote-debugging-port`
3. 首次注入时自动修改快捷方式/环境变量
4. 后续注入时直接连接已有端口
5. 新增 12 个测试

**预期收益**：
- 首次注入后，后续换肤无需重启目标应用
- 用户体验显著提升

---

### 方案 B：Canvas 自动配色分析器（P0）

**目标**：实现从上传图片自动提取主题配色的功能。

**实现路径**：
1. 新增 `src/shared/utils/palette-analyzer.ts`
2. 使用 Canvas API 分析图片亮度/主色/焦点/安全区
3. 自动生成 14-token 兼容的主题 JSON
4. 集成到 Studio 页面
5. 新增 15 个测试

**预期收益**：
- 用户上传图片即可生成主题
- Studio 智能化提升

---

### 方案 C：CSS 粒子动态特效引擎（P1）

**目标**：实现轻量级 CSS 粒子动态背景特效。

**实现路径**：
1. 新增 `src/engine/effects/particle-engine.ts`

3. 尊重系统"减少动态效果"设置
4. 可配置粒子数量/速度/颜色
5. 新增 10 个测试

**预期收益**：
