## 2. 核心发现与行业趋势

### 趋势 1：macOS menu bar 用量追踪成为 AI 客户端标配

- 版本 v4.6.1，迭代极其活跃

### 趋势 3：DSH（DeepSeek Harness）插件生态重塑 Agent 界面

**dsh-deep-whale 的皮肤架构**：

**dsh-web-ui 的工程化**：

### 4.1 aqua5230/usage — macOS menu bar AI 用量追踪

> **一句话**：macOS menu bar 小工具，把 Claude Code 跟 Codex 的用量钉在屏幕右上角，零 API 调用。

**核心数据**：

| 指标 | 数据 |
|------|------|
| Stars | — |
| Commits | 305 |
| 最新版本 | v0.15.4 |
| 最后更新 | 2026-08-24 |
| 技术栈 | Python + py2app |
| 支持平台 | macOS |

**技术亮点**：

1. **statusLine hook 机制**：
   - Claude Code 每次刷新状态列时，把 JSON 通过 stdin 喂给 hook
   - hook 写入 `~/.claude/usage-status.json`
   - menu bar 读取该文件显示

2. **Antigravity quota loader**：
   - 新增支持 Antigravity 用量加载
   - 与 AgentSkin 的 doubao 适配器直接相关

3. **burn rate 警告**：
   - 修复 burn-rate 警告误报
   - 支持 5 小时 / 7 天 / 今日统计

4. **零 API 调用**：
   - 用量数字来自本机的 Claude Code / Codex 文件
   - 唯一例外：估算 Codex 成本时需要 token 单价表
   - 支持 LiteLLM 价格表缓存（7 天过期）

**可借鉴点**：

## 6. 行业趋势总结

1. **用量监控本地优先**：aqua5230/usage 代表了一种趋势——用量数据来自本机文件，零 API 调用，保护用户隐私。

2. **AI 账号管理专业化**：Antigravity-Manager 的 29.9k stars 证明 AI 账号管理是一个巨大的市场，但 AgentSkin 不应涉足此领域（与视觉定制定位不一致）。

3. **DSH 插件生态爆发**：DeepSeek Harness 的"一切皆插件"设计理念正在重塑 Agent 界面，皮肤插件（dsh-deep-whale）和 UI 插件（dsh-web-ui）成为社区热点。

4. **一张图生成配色成为标配**：HeiGeAi/deepseek-harness-skin 和 AgentSkin 的 palette-extractor.ts 都支持此功能，证明这是用户刚需。
