## 2. 核心发现与行业趋势

### 趋势 1：场景感知注入成为 WorkBuddy 新方向
`sutongwuyanzu/WorkBuddy-Skin-` 的 `renderer-inject.js` 通过检测 `.wb-scene-tabs__pill` 自动切换 `wb-dash-active` 类，实现"照片只在仪表盘显示，聊天界面不显示"的智能 UX。这解决了"背景图遮挡文字"的痛点。

### 趋势 2：皮肤构建工具链工程化
`kongxcer555/codex-skin-builder` 的 `scaffold_skin.py` 是首个将皮肤构建 product 化的工具：输入 PNG/GIF → 输出完整皮肤包（CSS + 注入器 + 安装/验证/恢复脚本 + skin.json）。其 QA 清单（语法检查、隔离安装、截图验证、往返恢复）是工程化的典范。

### 趋势 3：原生托盘应用回归
`z0rgoyok/codex-theme-controller` 使用 SwiftUI 构建原生 macOS 托盘应用，自动发现运行中的 Codex 进程，一键应用主题。这比 Electron 更轻量，比 CLI 更友好。

### 趋势 4：WorkBuddy 主题生态爆发式增长
本轮发现两个新的 WorkBuddy 主题项目（zhouwei713、sutongwuyanzu），加上之前覆盖的 cdredfox、leeandrew94、Christina121877 等，WorkBuddy 已成为仅次于 Codex 的换肤生态。

### 趋势 5：TRAE Work 生态开始萌芽
`Iwsport4674/TRAE-Work-Dream-Skin` 是首个专门针对 TRAE Work 的换肤项目（之前只有 captainfod 的 fork），表明 TRAE Work 用户开始产生换肤需求。
