## 2. 核心发现与行业趋势

### 趋势 1：跨平台"母舰级"主题管理器崛起
`dream-work-theme` 过去三周的爆发式迭代（10+ commits，新增 3 个平台支持）表明，行业正从"单应用换肤"走向"统一主题中心"。其 `app-registry.ts` 注册 15+ Electron 应用的架构，是 AgentSkin 六适配器模式的另一种实现路径。

### 趋势 2：CDP 基础设施工程化
`zcode-cdp` 把 CDP 从"调试工具"提升为"生产级基础设施"：端口租约池（7 并发）、三层看门狗（软/CPU/硬）、状态机懒加载（IDLE→ACTIVE）。这标志着 CDP 注入技术从"脚本玩具"走向"工程级框架"。

### 趋势 3：AI 编排主题生成
`codex-theme-studio-skill` 展示了"文本/图片 → 完整主题"的 AI 编排能力。其"五区视觉契约"（左品牌/中沉浸/右主体/底输入/右下卡片）是首个把 UI 设计规则编码为可执行契约的实现。

### 趋势 4：热重载注入配置
`aios` 通过 `/tmp/aios-config.json` + `fs.watchFile` 实现 1 秒级热重载。这种"配置文件即注入"的模式虽需一次性修改入口文件，但运行时灵活性极高。

### 趋势 5：CDP REPL 工具沉淀
`electron-inject` 作为早期（2025-03）CDP 注入范本，提供了交互式 REPL + REST API 的双模接口，是理解 CDP 注入原理的经典参考。

**技术亮点**：
1. **配置文件热重载**：`fs.watchFile('/tmp/aios-config.json')`，1 秒内自动重注入
2. **CDP 端点暴露**：主进程自动 `appendSwitch('remote-debugging-port', '9222')`
3. **三轨修改**：配置文件（热重载）/ CDP（一次性）/ Agent 替换（能力扩展）
4. **签名修复**：解包 asar → 修补入口 → 重打包 → ad-hoc 重签名

**与 AgentSkin 的关系**：

| 维度 | aios | AgentSkin |
|------|------|-----------|

| 平台 | macOS only | Windows / macOS / Linux |
| 配置驱动 | /tmp/aios-config.json | 14-token manifest |
| 持久化 | 配置文件持久 | IPC 主进程持久 |

**评估**：aios 的配置文件热重载思路有参考价值，但其"修改入口文件"方式与 AgentSkin"不修改官方应用"原则冲突，仅作为技术储备学习。

```
│  └─────┴─────┴─────┴─────┴─────┴─────┴─────┘                │
└───────────────────────────────────────────────────────────────┘
```

**核心机制详解**：

1. **端口租约池**：
   - 7 个临时端口（9223-9229）+ 固定脚本端口（9324/9326）
   - 原子 `mkdir` 抢锁 + `leaseId` ownership 校验
   - 防 PID 复用误删新锁
   - Stale 锁回收（30 秒无心跳）

2. **三层看门狗**：

| 层级 | 机制 | 阈值 | 动作 |
|------|------|------|------|
| 软看门狗 | 事件循环延迟检测 | 2000ms × 3 次 | 警告 |
| CPU 看门狗 | 主进程 CPU% busy-loop | 85% × 5/10 次采样 | 节流 |
| 硬看门狗 | 独立 worker 线程心跳 | 60s 无心跳 | SIGKILL |

3. **状态机懒加载**：

```
IDLE → ENSURING → ACTIVE → CLOSING → IDLE
  ↑                                    │
  └────────────────────────────────────┘
```

- 首次 `browser_*` 调用才启动 Chrome
- 不碰浏览器的窗口 = 0 Chrome 进程
- 循环关闭不重启 backend

4. **Profile 管理**：
   - `rsync` 从日常 Chrome 继承登录态
   - 每端口独立 profile + 卡通头像
   - `--refresh` 强制刷新

**与 AgentSkin 的关系**：

| 维度 | zcode-cdp | AgentSkin ZCode 适配器 |
|------|-----------|----------------------|
| 目标 | 浏览器接管（自动化） | 主题注入（换肤） |
| CDP 连接 | 端口租约池 | 单一连接 |
| 稳定性 | 三层看门狗 | 基础重连机制 |
| 状态机 | IDLE→ACTIVE 懒加载 | 持续连接 |
| Profile | rsync 继承登录态 | 不涉及 |

**重大更新标记**：
- **v0.2.0 relay 架构**（08/14）：本地 TCP 中继 + 单常驻 backend，删除双 backend 切换
- **标准回测体系**（08/14）：L0 静态 / L1 租约 / L2 状态机三层回归
- **openspec 规格驱动开发**（08/15）

**对 AgentSkin 的启示**：端口租约池和三层看门狗机制可直接增强 AgentSkin 的 ZCode 适配器稳定性和并发安全性。
