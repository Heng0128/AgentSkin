## 2. 核心发现与行业趋势

### 趋势 1：macOS 原生应用回归（Tauri 替代 Electron）
`CodeX-Skin`（aha-codex）使用 Tauri v2 构建独立的 macOS 换肤工作室应用，而非 Electron。这标志着行业开始追求更轻量的原生体验：
- 1:1 实时预览画布（真实 Codex 窗口同步）
- 视频背景支持（最大 30MB 无缝循环）
- 自动配色提取（拖图生成主题）
- minisign 签名校验更新包

### 趋势 2：Inspector 脉冲注入（无端口常驻）
`okkskin` 创新性地使用 `SIGUSR1` / `process._debugProcess` 向运行中的 Codex 主进程发送一次性 inspector 脉冲：
- 注入时临时开启调试端口
- 注入完成后立即关闭端口（`process._debugEnd`）
- 持久模式靠常驻 agent，每次 Codex 启动脉冲一次
- 解决了"调试端口长期暴露"的安全隐患

### 趋势 3：网页主题墙 + 实时换肤
`moonsea-codex-theme` 是目前首个实现"网页点一下，已打开的 Codex 立即换肤"的产品：
- 独立桌面助手（月海助手）+ 网页主题墙
- 支持 Windows 和 macOS
- **已扩展支持 WorkBuddy**（Install-WorkBuddy.cmd 存在）
- 自动更新（SHA-256 校验 + 断点续传）

### 趋势 4：极简 6 色主题契约
`okkskin` 将主题定义压缩到 6 个颜色 + 1 张壁纸 + 明暗标记：
- background / panel / accent / text / muted / line
- 人工按图手配，engine 自动套用
- 对话页纯色不铺壁纸（保可读性）

### 趋势 5：独立主题包生态持续分化
`sdbds/Codex-QingLong-Skin` 和 `Alhamdulillah-R/cyberpunk-codex-skin` 代表"单风格独立主题包"生态，通常是 Codex Dream Skin 的 fork + 自定义背景，技术含量低但满足特定审美需求。

## 6. 推荐最优解与实施结果

### 方案 A：Inspector 脉冲注入安全增强（P0）

**来源**：fanbidog/okkskin 的 Inspector 脉冲注入模式

**目标**：为 AgentSkin 的 CDP 注入层添加"临时端口"模式选项，避免调试端口长期暴露。
