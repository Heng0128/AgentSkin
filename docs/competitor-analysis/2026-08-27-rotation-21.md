**架构设计**:
```
安装脚本 → --remote-debugging-port=9339 → launchd 守护(10s 检测) → CDP 注入 → CSS 变量覆盖 + 壁纸 + 主题菜单
```

**核心文件结构**:
```
.
├── macos/
│   ├── engine/src/
│   │   ├── cdp.mjs          # CDP 连接
│   │   ├── cli.mjs          # CLI 接口
│   │   ├── config.mjs       # 配置管理
│   │   ├── css.mjs          # CSS 变量生成

│       └── uninstall-dream-skin-auto.sh
└── docs/
```

**技术亮点**:
1. **launchd 守护进程** — 每 10s 检测 WorkBuddy 端口，丢失则自动重启恢复
2. **CSS 变量覆盖** — 使用 `--cb-*` 设计变量覆盖（与 AgentSkin 的 CSS 变量策略相似）
3. **自动恢复** — 重启后通过 localStorage 记录自动恢复上次主题
4. **零依赖引擎** — 纯 Node 22+（用全局 `WebSocket`），无需 `npm install`
5. **自定义壁纸取色** — 上传图片自动提取主色生成整套配色
6. **页面内主题菜单** — 右下角一键切换，无需外部 UI

**CLI 命令**:
```bash
node macos/engine/src/cli.mjs list          # 列出主题
node macos/engine/src/cli.mjs apply         # 应用主题
node macos/engine/src/cli.mjs status        # 查看注入状态
node macos/engine/src/cli.mjs pause         # 临时还原
node macos/engine/src/cli.mjs create        # 创建自定义主题
```

#### 与 AgentSkin 对比

| 维度 | shaozhengmao/workbuddy-dream-theme | AgentSkin |
|------|-----------------------------------|-----------|
| 平台 | 仅 macOS | Windows/macOS/Linux |
| 守护进程 | launchd (macOS 专属) | 跨平台 watchdog |
| CSS 变量 | `--cb-*` 变量 | 14-token 契约 |
| 自动恢复 | launchd + localStorage | 持久化 + 自动注入 |
| 零依赖 | 纯 Node 22+ | Electron 应用 |

## 三、行业趋势与关键发现

### 趋势 1：WorkBuddy 换肤生态涌现大量轻量方案
本期 4/5 个项目围绕 WorkBuddy，且全部采用"macOS 优先 + 纯 Node/CDP + launchd 守护"的技术路线。这反映出：
- WorkBuddy 已成为国内 AI 客户端换肤的主战场
- 轻量化方案（脚本 + CDP + 守护进程）是当前主流
- macOS 平台因 launchd 生态而成为首选

### 趋势 2：Agent Skill 换肤成为新范式
`TimekeeperXY/workbuddy-dream-skin-skill` 和 `huangama666/workbuddy-skin`（含 SKILL.md）都将换肤能力封装为 Agent Skill，让 AI Agent 自动完成 DOM 审计 → 选择器映射 → 主题生成 → 注入 → QA 全流程。这与 AgentSkin 的"引擎"定位形成互补。

### 趋势 3：主题工作室 UX 趋于成熟
`charmber/codex-skin` 展示了完整的主题工作室模式：10 项配色 + 双布局 + 头像系统 + 文案编辑 + 导入导出。这正在成为桌面换肤工具的标准 UX。

### 趋势 4：CSS 变量覆盖成为主流注入方式
`shaozhengmao/workbuddy-dream-theme` 的 `--cb-*` 变量和 `huangama666/workbuddy-skin` 的 CSS 覆盖都采用 CSS 变量/选择器策略，而非直接修改 DOM。这与 AgentSkin 的 CSS 注入策略一致。

## 四、AgentSkin 差距评估

### 已领先领域
1. ✅ **跨平台覆盖** — AgentSkin 支持 Windows/macOS/Linux 三平台，竞品多为 macOS 专属
2. ✅ **多应用适配** — 6 款应用适配器，竞品多为单应用
3. ✅ **14-token 契约** — 比竞品的 4-10 项配色更系统化
4. ✅ **自动化注入** — 无需手动 DevTools Console 操作

### 可改进领域
1. ⚠️ **macOS 守护进程** — AgentSkin 缺少 launchd 集成（仅跨平台 watchdog），macOS 用户体验不如 shaozhengmao 方案
2. ⚠️ **可视化主题创作** — charmber 的 10 项配色实时预览 UX 更成熟
3. ⚠️ **对话头像系统** — 竞品已支持分别设置用户/助手头像
4. ⚠️ **主题导入导出** — 竞品已支持 `.zip`/`.wbskin` 主题包分享

## 五、推荐方案

### R1: macOS launchd 守护集成 ⭐⭐⭐ (中优先级)
**来源**: shaozhengmao/workbuddy-dream-theme

- 崩溃自动重启恢复
- 与现有 watchdog.ts 互补（watchdog 负责进程级，launchd 负责系统级）

**来源**: charmber/codex-skin
**方案**: 在 14-token 契约中新增 avatar tokens，支持用户/助手头像分别设置
