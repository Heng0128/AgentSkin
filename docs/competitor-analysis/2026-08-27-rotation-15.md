### 2.2 CodeDrobe/desktop + CodeDrobe/core — 统一平台方案

**CodeDrobe/desktop (51 stars, TypeScript, Electron)**
- v2.1.1，支持 macOS DMG/zip + Windows Setup/Portable/MSI
- 自动更新：macOS Squirrel.Mac + Windows NSIS 静默安装
- 文件关联：.codedrobe-theme / .codex-theme
- 拖放导入主题包
- 同 id 导入确认替换机制

**CodeDrobe/core (9 stars, JavaScript)**
- v0.7.0-beta.0，npm 发布 @codedrobe/core
- 完整 CLI：inspect → probe → apply → verify → publish
- 支持应用：Codex, WorkBuddy, QoderWork, TRAE SOLO
- DevToolsActivePort 文件读取（处理 remote-debugging-port=0）
- **per-window probe/verify** — 逐窗口探测兼容性
- **avatar-overlay 排除** — Codex 隐藏窗口自动跳过

**关键发现**
1. **per-window probe/verify（高价值）**
   - Codex Desktop 的隐藏 `app://-/index.html?initialRoute=%2Favatar-overlay` 会误匹配主适配器
   - 解决方案：matchTarget 拒绝 avatar-overlay 路由
   - probe/apply/verify 三阶段对 secondary window demote 为 skipped
   - 只要有一个 primary window 兼容就不阻断流程

2. **DevToolsActivePort 发现机制**
   - 读取 Chromium DevToolsActivePort 文件获取随机端口
   - 适用于 host 强制 remote-debugging-port=0 的场景
   - macOS: 多 bundleId Spotlight 查询 + bundle 名推导 executable
   - Windows: Inno Setup AppId uninstall keys

3. **CLI 完整工作流**
   - `theme publish` — 上传包到商店
   - `theme search / download` — 搜索下载（SHA-256 完整性校验）
   - `theme.catalog` — 分类管理
   - JSON Schema 验证 theme.json

4. **自动更新机制**
   - macOS: Squirrel.Mac 内置更新器
   - Windows: NSIS 静默安装 (/S --force-run)
   - 共享 UpdateAction UI：下载进度条 + 重启安装按钮

**可借鉴点**
- per-window probe/verify 机制（高优先级，直接解决 AgentSkin 多窗口场景痛点）
- avatar-overlay 排除逻辑（高优先级，避免误匹配）
- DevToolsActivePort 发现（中优先级，提升 CDP 连接鲁棒性）
- 自动更新机制（低优先级，当前 AgentSkin 有自己方案）

## 四、推荐执行方案（按优先级排序）

### P0 — per-window 探测与验证增强（CodeDrobe 核心亮点）

**目标**：解决多窗口场景下的 CDP 探测和主题验证问题

**实现思路**：
1. 增强适配器 matchTarget 逻辑，排除不相关的 secondary window（如 Codex avatar-overlay）
2. probe 阶段逐窗口探测兼容性，demote 不兼容窗口为 skipped
3. verify 阶段确保至少一个 primary window 兼容即通过
4. apply 阶段按窗口分别注入

**影响范围**：engines/ 目录下的适配器逻辑

### P1 — 构建产物签名验证（FeiGe 方案）

**目标**：提升主题包和安装包的安全性

**实现思路**：
1. 主题包构建时生成 SHA256SUMS
2. 安装包发布时附带 SHA256SUMS.txt
3. 可选：GPG 签名发布（需用户配置 GPG key）

**影响范围**：scripts/ 构建脚本

### P2 — DevToolsActivePort 发现增强（CodeDrobe core）

**目标**：处理 remote-debugging-port=0 场景下的 CDP 端口发现

**实现思路**：
1. 读取 Chromium DevToolsActivePort 文件
2. macOS: 多 bundleId Spotlight 查询
3. Windows: Inno Setup AppId 查询

**影响范围**：engines/ CDP 连接层
