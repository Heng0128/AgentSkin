## 四、推荐方案

### P0: 主题实时预览功能

**目标**: 用户在选择主题时，无需实际应用即可看到效果预估。

**方案**:
1. 在 ThemeCard 组件中增加"预览"按钮
2. 点击后弹出预览面板，展示该主题的配色方案 + 模拟 UI 效果
3. 使用 CSS 变量注入到预览容器，不实际应用

**涉及文件**:
- `src/ui/components/themes/ThemeCard.tsx` — 增加预览按钮
- `src/ui/components/themes/ThemePreview.tsx` — 新增预览组件
- `src/ui/stores/themeStore.ts` — 增加 previewTheme action

**风险评估**: 低，纯前端功能，不影响注入逻辑。

---

### P1: 主题导入导出功能

**目标**: 用户可以将自定义主题导出为文件，或导入他人分享的主题。

**方案**:
1. 导出：将当前主题打包为 `.agentskin-theme` 文件 (JSON + 资源)
2. 导入：解析 `.agentskin-theme` 文件，验证后添加到主题库
3. 格式：ZIP 压缩包，包含 manifest.json + CSS + 资源文件

**涉及文件**:
- `src/main/theme/export.ts` — 导出逻辑
- `src/main/theme/import.ts` — 导入逻辑
- `src/ui/stores/themeStore.ts` — 增加 exportTheme/importTheme action

**风险评估**: 中，需要处理文件解析和验证。

---

### P1: 桌面安装包封装

**目标**: 提供 dmg (macOS) 和 exe (Windows) 安装包，降低非技术用户门槛。

**方案**:
1. 使用 `electron-builder` 配置 dmg/exe 输出
2. 配置代码签名 (macOS: Developer ID, Windows: EV 证书)
3. 配置自动更新 (electron-updater)

**涉及文件**:
- `package.json` — electron-builder 配置
- `.github/workflows/release.yml` — CI/CD 自动构建

**风险评估**: 中，需要代码签名证书。

---

### P2: 视频背景支持

**目标**: 支持将视频文件作为主题背景。

**方案**:
1. 在主题 manifest 中增加 `backgroundVideo` 字段
2. 注入时创建 `<video>` 元素作为背景层
3. 提供视频压缩和格式转换工具

**涉及文件**:
- `src/engines/injectors/` — 注入器支持视频背景
- `src/shared/types/theme.ts` — 增加视频背景类型
- `scripts/build-theme-package.mjs` — 支持视频资源打包

**风险评估**: 中高，需考虑性能影响和低配设备兼容性。
