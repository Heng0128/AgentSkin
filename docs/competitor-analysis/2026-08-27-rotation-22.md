### 1.1 基础数据

### 1.2 核心架构

CodeDrobe 是目前与 AgentSkin 定位最接近的竞品，采用三层架构：

1. **Desktop** — Electron 桌面应用，内置主题商店
2. **Core CLI** — `@codedrobe/core` npm 包，提供 apply/verify/restore/pack 命令
3. **Skills** — Agent 技能，给编码 Agent 一张参考图自动生成主题

### 1.3 技术亮点

#### 1.3.1 AI DOM 驱动的主题生成

这是 CodeDrobe 最核心的差异化能力：

- AI 读取应用实时界面结构（DOM）
- 照着真实结构现场生成整套 CSS
- 侧边栏、会话区、输入框、按钮、卡片全部重做
- 应用界面结构变了，重新读一遍再生成就行

**对比 AgentSkin**：AgentSkin 是预定义 CSS 文件注入，不读 DOM。CodeDrobe 的方式抗应用更新能力更强。

#### 1.3.2 统一主题包格式 `.codedrobe-theme`

- 一个文件 = 一个主题（清单 + CSS + 内嵌图片）
- 一个包适配多个应用（同一套视觉，装哪个应用就用哪份 CSS）
- 规则写死在 schema 里（主题声明依赖哪些界面节点）
- 零 JavaScript（声明式配置 + CSS + 图片）
- 安装前做兼容性预检

**对比 AgentSkin**：AgentSkin 使用 `manifest.json` + 分离的 CSS 文件结构，没有内嵌图片的统一打包格式。

#### 1.3.3 适配器协议

- 内置适配器：codex, workbuddy, qoderwork, traework
- 适配器协议开放，加个适配器就能接入新应用
- 通过 loopback CDP 注入，不改 app.asar

### 1.4 可借鉴的设计

| 设计点 | 可行性 | 优先级 | 说明 |
|--------|--------|--------|------|
| AI DOM 驱动 CSS 生成 | 高 | P1 | 可大幅增强主题抗更新能力 |
| 统一单文件格式 | 中 | P2 | 需修改 bundle 格式，需 RFC |
| 兼容性预检机制 | 高 | P1 | 可在应用主题前检测选择器是否匹配 |
| 主题商店模式 | 低 | P3 | 需服务端，违反项目约束 |

### 1.5 与 AgentSkin 的差异

| 维度 | AgentSkin | CodeDrobe |
|------|-----------|-----------|
| 注入方式 | CDP 注入 | CDP 注入 |
| CSS 生成 | 预定义 CSS 文件 | AI 实时读 DOM 生成 |
| 主题格式 | manifest.json + 分离 CSS | .codedrobe-theme 单文件 |
| 适配器数量 | 6 个 | 4 个 |
| 商店 | 无 | 有 (codedrobe.app) |
| 开源程度 | 全开源 | 全开源 |

## 六、行业趋势总结

### 6.1 关键趋势

1. **AI DOM 驱动的主题生成成为新范式** — CodeDrobe 引领这一趋势
2. **Agent-Native 换肤兴起** — codex-autoskin 代表的方向
3. **统一主题包格式** — 单文件格式成为趋势
4. **跨平台兼容** — 一个主题包适配多个应用
5. **社区插件生态** — codex-plusplus 的 tweak 模式

### 6.2 真实缺口识别

| 缺口 | 当前状态 | 建议 |
|------|----------|------|
| AI 实时 DOM 读取 + CSS 生成 | AgentSkin 缺失 | 高优先级实现 |
| 图片驱动主题生成 | AgentSkin 有壁纸但无图片→主题 | 中优先级实现 |
| 兼容性预检 | AgentSkin 无 | 高优先级实现 |
| 统一单文件格式 | AgentSkin 使用分离文件 | 需 RFC |

## 七、推荐执行方案

### 7.1 P0 — 兼容性预检机制（立即执行）

**目标**：在应用主题前检测选择器是否匹配，避免错位样式

**实现方案**：
- 新增 `scripts/verify-selectors.mjs` 脚本
- 在应用主题前运行预检
- 输出不匹配的选择器列表
- 新增测试覆盖

### 7.2 P1 — 图片驱动主题生成增强

**目标**：用户上传图片自动生成完整主题（不仅是壁纸）

**实现方案**：
- 扩展 `scripts/derive-missing-tokens.mjs`
- 从图片提取完整 14-token 配色
- 生成完整 CSS 而不仅是壁纸
- 新增测试覆盖

### 7.3 P2 — 热重载开发体验优化

**目标**：开发主题时实时预览效果

**实现方案**：
- 开发模式下监听文件变化
- 自动重新注入 CSS
- 无需重启目标应用
