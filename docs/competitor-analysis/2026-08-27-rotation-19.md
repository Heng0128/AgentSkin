### 2.1 waiterxiaoyy/codress — 主题商店 + 桌面宠物平台

#### 基本信息
- **定位**：Electron AI 工作空间外观工具（Codex + WorkBuddy）
- **版本**：v1.1.0（2026-07-26）
- **架构**：Electron 33 + React + Go API + MySQL
- **平台**：macOS / Windows
- **活跃度**：停滞（35 天无更新）

#### 核心亮点

**1. 主题商店 + 本地创建双轨模式**

Codress 同时提供：
- **Theme Store**：在线浏览、搜索、过滤 Codex/WorkBuddy 主题，一键应用
- **本地主题创建器**：预览和调整合成、图片处理、外观，共享 background/panel/text/accent 调色板

这与 AgentSkin 的 Studio 本地创作模式形成对比——Codress 更强调"商店发现"而非"本地创作"。

**2. 桌面宠物系统**

Codress 提供 Codex v2 桌面宠物和浮动桌面伴侣功能。这是一个差异化功能，AgentSkin 不具备。

**3. 安全边界设计**

```
- CDP 连接限制在回环地址
- WebSocket 目标检查预期形状和进程
- 商店主题包含图片和元数据，不含任意可执行代码
- 注入运行时随 Codress 客户端一起提供，不从主题包动态加载
- Codress 不修改目标应用程序目录或签名应用程序文件
```

**4. Claude Desktop 适配（已移除）**

有趣的是，Codress 曾添加 Claude Desktop 支持（2026-07-26），但随后在同一天提交"disable Claude skin support"将其移除，等待注入管道就绪。这说明：
- 多适配器的代码隔离做得好（移除不影响其他适配器）
- Claude 的注入管道与 Codex/WorkBuddy 不同

### 2.2 mcpso/awesome-codex-themes — 主题生态索引

#### 基本信息
- **定位**：Codex 主题/皮肤/工具的综合索引
- **Stars**：11
- **License**：CC0-1.0
- **活跃度**：停滞（42 天无更新）
- **网站**：https://codexthemes.ai

#### 核心内容

**1. 三层主题分类**

```
1. Codex CLI（终端 TUI）：32 内置语法主题 + .tmTheme 自定义
2. Codex 桌面应用：JSON 主题导入字符串（codex-theme-v1: 前缀）
3. Skins（CDP 注入）：CSS/壁纸运行时注入
```

**2. Codex 桌面应用主题格式**

桌面应用主题是 JSON payload，前缀为 `codex-theme-v1:`，字段包括：
- `codeThemeId`：必须匹配内置 ID（tokyo-night, one-dark, nord, dracula, catppuccin, gruvbox, github-light, matrix, one）
- `theme.accent`：强调色
- `theme.ink`：文本色
- `theme.surface`：背景色
- `theme.contrast`：对比度
- `theme.opaqueWindows`：不透明窗口
- `theme.fonts.{ui,code}`：字体
- `theme.semanticColors.{diffAdded,diffRemoved,skill}`：语义色
- `variant`：dark/light

**3. 关键发现：codexThemeId 限制**

> `codexThemeId` must match a built-in id (tokyo-night, one-dark, nord, dracula, catppuccin, gruvbox, github-light, matrix, one) — unknown ids fail silently. Theme authors work around this by reusing a built-in id and overriding all colors.

这说明 Codex 桌面应用的主题导入机制有白名单限制，主题作者需要复用内置 ID 并覆盖所有颜色。

**4. 收录工具**

- DexThemes：社区主题发现站
- samuxbuilds/codex-themes：1000+ 主题交互预览
- shaw-baobao/codex-themes：带预览和导入字符串
- Railly/tinte：Agent 原生设计系统编译器
- meownoid/meowtheme：多目标配色方案生成器
- Kronosnxs/codex-theme-builder：单文件 Web 应用

#### 可借鉴设计思想

| 编号 | 设计思想 | 可行性 | 预期价值 |
|------|---------|--------|---------|
| L4 | **主题导入字符串标准** | 高 | 可参考其 JSON 格式设计 AgentSkin 主题分享格式 |
| L5 | **codexThemeId 白名单机制** | 低 | AgentSkin 已有 14-token 契约，无需复用 |

### 2.5 chainshieldai/codex-cobalt-gold-theme — 运行时 Markdown 样式注入

#### 基本信息
- **定位**：Cobalt2 启发的 Codex 桌面主题包
- **Stars**：1
- **License**：MIT
- **语言**：JavaScript
- **活跃度**：**极高（2026-08-25 仍在更新）**
- **创建日期**：2026-04-30

#### 核心亮点

**1. 双模式主题应用**

- **正常主题导入**：使用 Codex 桌面应用的 Appearance 导入器
- **运行时样式**：使用 Chrome DevTools Protocol 注入 Markdown/编辑器 CSS

**2. 安全模型**

```
- 不修改 /Applications/Codex.app
- 不重新打包 app.asar
- 不更改代码签名
- 回退简单：npm run stop:runtime-css，然后正常重启 Codex
```

**3. 运行时 Markdown 样式注入**

这是该项目最核心的创新：
- 通过 CDP 连接到本地调试端口的 Codex 进程
- 插入 `<style>` 标签到活动渲染器文档
- 不修改官方二进制文件

**4. Markdown 调色板**

- `#` 标题：#FFC600 金色
- `##` 标题：#FF9D00 琥珀
- `###` 标题：#80FCFF 电青色
- 链接：斜体电青色
- 强调：琥珀
- 行内代码：金色在深蓝色上
- 围栏代码：深蓝色带金色内嵌规则
- 原生编辑器面板：内置 night-owl + Cobalt2 亮度提升覆盖

**5. 字体回退链**

```
Operator Mono, VictorMono Nerd Font Mono, VictorMono Nerd Font, JetBrainsMono Nerd Font Mono, JetBrainsMono Nerd Font, FiraCode Nerd Font Mono, Fira Code, SF Mono, Menlo, Monaco, Consolas, monospace
```

**6. 文件结构**

```
- dist/cobalt2-codex-paste.txt：Codex 桌面导入字符串
- dist/cobalt2-codex-paste.encoded.txt：URL 编码导入字符串回退
- dist/cobalt2-codex.codex-theme.json：解码导入负载
- dist/cobalt2-codex-full.codex-theme.json：完整源衍生元数据
- overrides/cobalt2-markdown-overrides.css：运行时 Markdown CSS
- scripts/start-runtime-css.mjs：正常配置文件运行时启动器
- scripts/inject-runtime-css.mjs：DevTools Protocol CSS 注入器
```

## 三、跨项目横向对比

### 3.1 行业趋势

**1. 主题商店平台化**
- Codress 的在线商店 + API 模式代表了一种"平台化"趋势
- 但 Codress 本身停滞，说明纯主题商店模式可能缺乏持续动力

**2. 运行时 Markdown 样式注入兴起**
- Cobalt Gold 的运行时 Markdown 样式注入是一个新方向
- 目前 AgentSkin 没有 Markdown 渲染样式注入能力

**3. 主题格式标准化**
- Codex 桌面应用的 `codex-theme-v1:` JSON 格式已成为事实标准
- 多个工具（DexThemes, samuxbuilds, shaw-baobao）都输出此格式

**4. 中文市场需求旺盛**
- codexskin.cn 和 roland-luo/codex-dream-skin 都针对中文用户
- 中文用户对 Codex 换衣有强烈需求

### 3.2 AgentSkin 的差异化优势

| 能力 | AgentSkin | 最强竞品 | 差距 |
|------|-----------|---------|------|
| 工程质量体系 | 10 不变量 + 全量校验脚本 | Codress（无） | AgentSkin 完胜 |
| 14-token 主题契约 | 编译时保证跨应用一致性 | Cobalt Gold（无） | AgentSkin 完胜 |
| 六适配器深度适配 | 每个应用独立优化 | Codress（2 款） | AgentSkin 完胜 |
| Windows + macOS 双端 | 覆盖最大用户群 | Cobalt Gold（仅 macOS） | AgentSkin 完胜 |
| 豆包完整注入 | doubao 适配器已上线 | 无 | AgentSkin 完胜 |

### 3.3 AgentSkin 的差距

| 差距项 | 竞品领先者 | 现状 |
|--------|-----------|------|
| 运行时 Markdown 样式注入 | Cobalt Gold | AgentSkin 无此能力 |
