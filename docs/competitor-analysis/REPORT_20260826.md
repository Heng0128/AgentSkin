## 二、核心发现

### 2.1 行业趋势

**母舰化收编加速**：dream-work-theme 两周内支持 18 个 AI 桌面应用，验证了 CDP 注入的跨平台通用性。AgentSkin 的 6 适配器策略（精选而非广撒网）在工程质量上仍具优势，但覆盖广度差距明显。

**安全模型分化**：LingGlow 的"声明式 JSON + 零 JS + Pipe-only CDP"与 CodeDrobe 的"运行时 DOM 探测 + 选择器 lint"代表两种安全路线。AgentSkin 的 14 token 静态契约介于两者之间（比自由 CSS 更安全，比声明式 JSON 更灵活）。

**AI 创作工作流兴起**：CodeDrobe/skills（244 star）的"参考图 → DOM 快照 → CSS 生成 → 验证"闭环代表了主题创作的发展方向。workbuddy-skin-studio 的客户端实时取色则是轻量化的 AI 替代方案。

### 2.2 AgentSkin 的差异化优势（竞品不具备）

| 能力 | AgentSkin | 最强竞品 | 差距 |
|------|-----------|---------|------|
| 工程质量体系 | 10 不变量 + 全量校验脚本 | CodeDrobe（无） | AgentSkin 完胜 |
| 14-token 主题契约 | 编译时保证跨应用一致性 | dream-work-theme（4 token） | AgentSkin 完胜 |
| Windows + macOS 双端 | 覆盖最大用户群 | LingGlow（仅 macOS） | AgentSkin 完胜 |
| 六适配器深度适配 | 每个应用独立优化 | dream-work-theme（通用注入） | AgentSkin 优势 |
| 豆包完整注入 | doubao 适配器已上线 | LingGlow（blocked） | AgentSkin 完胜 |

### 2.3 AgentSkin 的差距（竞品领先）

| 差距项 | 竞品领先者 | 现状 |
|--------|-----------|------|
| 从图片自动创建工作流 | workbuddy-skin-studio、CodeDrobe/skills | AgentSkin 需手动配置配色 |
| 兼容性降级策略 | LingGlow（3 档分级） | AgentSkin 是全有/全无模式 |
| 主题包标准化 | CodeDrobe（.codedrobe-theme） | AgentSkin 格式仅内部使用 |
| 选择器健壮性检查 | CodeDrobe（lint 警告） | AgentSkin 依赖人工审查 |
| zcode 并发安全 | zcode-cdp（原子租约） | AgentSkin 当前无端口竞争防护 |

## 四、各项目详细分析摘要

### 4.1 dream-work-theme — 跨平台母舰引擎（xxxhh336）

**一句话**：两周内从零到 18 应用支持的快速迭代工具，工程质量不可持续但踩坑经验宝贵。

**核心数据**：
- 创建 2026-08-05，最近提交 2026-08-21
- 18 个应用，6/6 覆盖 AgentSkin 目标
- Apache-2.0，Electron + Vite + TS
- 无测试、无 CI、2 人贡献

**AgentSkin 不可借鉴**：
- 硬编码端口表（违反 C1 AgentId 四源一致）
- 4-token 色彩体系（违反 C2 14-token 契约）
- 无校验脚本快速发布（违反 check 全绿铁律）
- ASAR 修改（安全风险）

**AgentSkin 可借鉴**：
- 主题 compat 白名单（L2）
- CDP 预启动 TCP bind 验证（注入前确认端口）
- Playwright 辅助绕过参数清除（codex 适配器储备）
- watcher 自动重注入（renderer 重建后恢复）

### 4.2 zcode-cdp — CDP 端口租约代理（Lumos-789）

**一句话**：解决多 Agent 并发时 CDP 端口竞争问题的微型框架，设计精良。

**核心数据**：
- 创建 2026-08-01，最近提交 2026-08-15
- MIT 许可证，纯正 JS/Bash，零框架
- v0.2.0 relay 架构重构，状态机从 9→4

**核心创新**：
- `mkdir` 原子抢占 + leaseId + PID 启动时间三元组防复用
- Relay 挂起语义（无 upstream 时挂起，就绪后自然流动）
- 三层看门狗（软→CPU→硬 worker）

**AgentSkin 评估**：AgentSkin 不走端口模式走进程注入，端口竞争不是当前瓶颈。但 leaseId 思路可作为 zcode 适配器的远期储备。

### 4.3 workbuddy-skin-studio — 图片取色换肤（cdredfox）

**一句话**：一人 48 小时交付的轻量 WorkBuddy 换肤工具，独创实时取色算法。

**核心数据**：
- 创建 2026-07-16，代码停滞 40 天
- 164 star / 24 fork，MIT
- 贡献者 1 人（fei.yang），10 次 commit

**核心创新（可直接移植）**：
- `extractPalette`：降采样 48px → HSL 色相分桶（12 桶）→ 饱和加权 → 主色/辅色选取
- CSS 模板 + 哨兵替换（`.split().join()`）
- Surface 明度 >140 自动判深浅
- 客户端图片压缩（1600px + webp 0.8）

**AgentSkin 应用方向**：L1（Studio 图片取色功能）+ L3（模板替换模式）

### 4.4 LingGlow — macOS 安全换肤（AI-Scarlett）

**一句话**：安全意识极强的 macOS 独占工具，豆包适配卡在 blocked 但方法论可借鉴。

**核心数据**：
- v2.3.18，源码 2026-07-29 公开
- MIT，macOS 13+，SwiftUI 菜单栏 + 内嵌 Node.js
- 支持 WorkBuddy(exact) + Codex(generic-safe) + 豆包(blocked)

**核心创新**：
- 三档兼容分级：exact / generic-safe / blocked
- 声明式皮肤 JSON + SHA-256 + 零 JS
- Pipe-only CDP（`--remote-debugging-pipe`）
- 静态指纹全覆盖（artifactSha256）
- lsof 进程证明清理
- 安全失败（fail-closed）原则

**AgentSkin 评估**：豆包适配能力远弱于 AgentSkin。主要借鉴价值在兼容性分级策略（L4）和选择器健壮性意识。

### 4.5 CodeDrobe/core — 统一换肤平台（CodeDrobe Org）

**一句话**：试图建立桌面 AI 应用换肤"App Store"的开源核心，格式标准化野心勃勃。

**核心数据**：
- v0.7.0-beta.0，5 天 9 版本
- 生态三件套：core(9★) / desktop(50★) / skills(244★)
- Apache-2.0，纯 JS ESM，零运行时依赖

**核心创新**：
- `.codedrobe-theme` JSON 单文件格式
- schemaVersion + 多 target.targets.<app> CSS
- 选择器 lint 警告（位置选择器、过深链、生成类名）
- probe → apply → verify 三阶段验证
- 按窗口判定 + 启动中页面重试预算
- Skill 驱动的 AI 创作闭环

**AgentSkin 评估**：14-token 契约与 CodeDrobe 的自由 CSS 模型不兼容（不应替换）。可借鉴 lint 思维和注入前探测。
