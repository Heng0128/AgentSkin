## 2. 核心发现与行业趋势

### 趋势 1：Tauri v2 + Rust 成为 Electron 的轻量替代方案
`Cmochance/agent-theme` 是目前唯一使用 Tauri v2 + Rust 技术栈的换肤应用：
- 前端：Svelte + Tailwind CSS
- 后端：Rust + Tauri v2
- CDP 注入：通过 Rust 后端执行
- 图片处理：Canvas 裁剪 + Base64 编码
- 状态管理：Polling 15s 间隔刷新

### 趋势 2：CDN 托管 + CI 验证成为主题资产管理的最佳实践
`aithink001/Codex-Dream-Skin-Themes` 开创了"仓库零图片二进制"模式：
- 所有图片通过 HTTPS CDN 加载
- CI 强制验证：`assert not images`（禁止提交图片到仓库）
- `themes.json` 机器可读格式（含 prompt + CDN URL）
- 主题 profile 管理（safeArea + taskMode）
- 46 stars（本轮最高星），证明社区对轻量仓库的认可

### 趋势 3：桌面四入口 UX 成为专业换肤工具的标准配置
`fufu1209/Codex-Dream-Skin-Aurora` 的桌面命令模式正在被社区广泛采用：
- **Start** — 启动带主题的 Codex
- **Customize** — 从图片定制主题
- **Verify** — 实时验证并截图
- **Restore** — 一键恢复官方外观
- 客户交付 ZIP 含隐藏引擎目录（.codex-dream-skin-studio）
- 完整的"给 Codex 的部署提示词"（自动化部署流程）

### 趋势 4：单文件 PowerShell 安装器降低 Windows 用户使用门槛
`zh1665/cobalt-for-codex` 验证了"一键运行"模式的市场需求：
- 单文件 `.ps1`，右键"使用 PowerShell 运行"
- TOML 配置操作（创建/修改/删除 section）
- UTF-8 without BOM 输出（避免 Codex 解析错误）
- 自动备份机制（`config.toml.cobalt-for-codex-backup-YYYYMMDD-HHMMSS`）
- 零依赖（纯 PowerShell，无需 Node.js）

### 趋势 5：应用内主题中心 + 看门狗持久化
`ismoshushi/codex-skinkit` 实现了最完整的 Windows 端主题切换体验：
- 应用内主题中心（右上角入口，无需重启切换）
- 5 套内置主题 + 4 种环境特效（火花/轨道扫描/极光/花瓣）
- 看门狗机制（Codex 重启后自动恢复主题 + 重试熔断）
- 本地 IndexedDB 存储（上传主题不上传网络）
- 减少动态效果支持
- 三布局家族：电影横幅/沉浸面板/指挥中心

## 5. 行业趋势总结

### 5.1 桌面四入口 UX 成为专业标准
从 Aurora 项目可以看出，专业换肤工具正在向"启动/定制/验证/恢复"四入口模式演进：
