## 3. 各项目详细分析

### 3.1 majiabin2020/workbuddy-theme-skin-skill — WorkBuddy CDP 注入换肤

#### 3.1.1 核心架构

```
用户 → SKILL.md 工作流 → 取色脚本(Python+Pillow) → CSS 模板生成 → CDP 注入 → WorkBuddy
```

#### 3.1.2 技术亮点

**1. 图片自动取色（extract_colors.py）**
- 使用 Python Pillow 库从参考图片提取主色调
- 生成覆盖全部 UI 区域的 CSS 主题
- 自动适配深色/浅色模式

**2. CSS Modules 类名匹配**
- WorkBuddy 使用 React CSS Modules，类名含哈希后缀（如 `_assistantRow_14nyt_184`）
- 使用 `[class*="prefix"]` 属性选择器匹配
- 这是 AgentSkin WorkBuddy 适配器已经解决的问题，但本方案提供了另一种思路

**3. MutationObserver 对抗 React 重渲染**
- 使用 MutationObserver 持续监听 DOM 变化
- 在 React 重渲染后重新注入样式
- 这与 AgentSkin 的 secondaryInjectStore 机制类似

**4. 完整工作流**
- SKILL.md 驱动的工作流（205 行）
- 包含取色脚本、CSS 模板、CDP 注入器、DOM 探查工具、启动器模板
- 支持一键恢复原版

#### 3.1.3 与 AgentSkin 对比

| 维度 | workbuddy-theme-skin-skill | AgentSkin WorkBuddy 适配器 |
|------|---------------------------|---------------------------|
| 注入方式 | CDP（环境变量 WORKBUDDY_REMOTE_DEBUGGING_PORT） | CDP（自动探测端口） |
| 主题格式 | 单一 CSS 模板 | 14-token 严格契约 |
| 类名匹配 | `[class*="prefix"]` 属性选择器 | 适配器定义稳定 landmark |
| 持久化 | 启动器脚本 | 持久化存储 + 自动重注入 |
| 图片取色 | Python Pillow 取色 | 不支持 |
| 恢复机制 | 一键恢复原版 | 主题还原 |

#### 3.1.4 可借鉴设计
- **图片自动取色**：可考虑在 Studio 中添加"从图片生成主题"功能（需 RFC）
- **CSS Modules 类名匹配策略**：作为 WorkBuddy 适配器 landmark 的补充方案

### 3.2 Aealen/zcode-hooks-poc — ZCode Hook 机制 PoC

#### 3.2.1 核心架构

```
ZCode 客户端 → Hook 机制 → 拦截工具调用/权限询问 → 浏览器 UI 展示 → 用户决策 → 回传 ZCode
```

#### 3.2.2 技术亮点

**1. PermissionRequest 反向控制闭环**
- 拦截 write/edit/bash 权限请求
- 在浏览器 UI 展示事件流与询问卡片
- 用户作答后决策回传给 ZCode
- 实现"权限请求→用户审批→执行"的完整闭环

**2. AskUserQuestion 完全接管**
- 拦截 ZCode 的 askUserQuestion 机制
- 支持中文 other 自定义输入
- v2.1.0 端到端实测通过

**3. Hook 机制探索**
- 搞清楚 hook 能做什么、不能做什么、怎么稳定地做
- 聚焦机制本身，不做产品形态设想

#### 3.2.3 与 AgentSkin 对比

| 维度 | zcode-hooks-poc | AgentSkin ZCode 适配器 |
|------|-----------------|----------------------|
| 目标 | 权限拦截 + 用户决策 | 主题注入 |
| 机制 | Hook 机制（客户端层） | CDP 注入（渲染层） |
| 安全边界 | 明确（只拦截不修改） | 明确（只注入 CSS） |

#### 3.2.4 可借鉴设计
- **Hook 机制安全边界**：了解 ZCode 客户端的可扩展性边界，避免适配器触发安全限制
- **权限拦截模式**：如果未来 AgentSkin 需要添加"注入安全审批"功能，可参考此模式

## 7. 实施结果（2026-08-27 06:45 完成）

### 7.1 方案 A：图片自动取色生成主题 ✅

**实施文件**：
- `scripts/extract-theme-from-image.mjs` — medianCut 量化 + 14-token 映射 + BMP/PNG 解码
- `scripts/extract-theme-from-image.test.mjs` — 38 个测试全部通过

**核心功能**：
- medianCut 量化算法（从 color-quantize.ts 移植）
- 14-token 契约映射（background, surface, text, muted, accent, border, primary, secondary, danger, warning, success, info, shadow, overlay）
- BMP（复用 oklch-extract decoder）+ PNG（Node.js 内置 zlib，零外部依赖）
- 深色/浅色自动检测（基于平均亮度）
- WCAG 安全修正（text/bg 对比度不足时自动推向纯白/纯黑）
