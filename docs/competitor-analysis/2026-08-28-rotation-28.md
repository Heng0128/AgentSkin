#### 基本信息

- **最近更新**: 2026-07-19（40 天前，已停滞）
- **平台**: macOS + Windows
- **版本**: v2.1.0 (core 0.6.0)

#### 技术实现

**核心架构**:
```
CodeDrobe Desktop (Electron)
├── src/main          # 主进程：IPC、文件、更新
├── src/shared        # 共享类型/工具
├── src/ui            # React + Tailwind + shadcn 组件
│   ├── assets/apps   # 应用图标
│   ├── components    # UI 组件
│   └── components/ui # 基础 UI 元素
├── assets/runtime    # 运行时资源
└── scripts           # 构建/打包脚本
```

**关键设计**:

1. **Deep Link 协议** — `codedrobe://themes/apply?theme=<slug>&app=<id>`
   - 网站一键安装并应用主题
   - 应用内确认后执行
   - 这是从 Web 到桌面应用的桥接标准

2. **OAuth 2.0 PKCE 登录** — 通过系统浏览器完成 OAuth 流程
   - 支持点赞、收藏同步
   - 分享动作

3. **智能应用流程**:
   - 运行中的应用 → 实时热替换
   - 停止的应用 → 启动时带主题
   - 仅首次启动或外观设置变更时才请求重启

4. **多应用支持** — 一个主题包可针对多个应用
   - Codex、WorkBuddy、QoderWork、TRAE SOLO
   - 详情抽屉按应用分别应用

5. **安全验证** — 每次下载对比市场 SHA-256 记录

#### 与 AgentSkin 对比

| 维度 | CodeDrobe/desktop | AgentSkin |
|------|-------------------|-----------|
| 定位 | 消费者主题商店 | 引擎 + Studio |
| 登录 | OAuth 2.0 PKCE | 无账号系统 |
| 主题来源 | 在线市场 + 自导入 | 本地 + 导入 |
| Deep Link | ✅ 支持 | ❌ 无 |
| 多应用 | 4 个应用 | 6 个适配器 |
| 商店 | codedrobe.app | 无 |

#### 可借鉴点

1. **Deep Link 协议** — AgentSkin 可借鉴实现 `agentskin://` 协议，支持从网页一键安装主题
2. **热替换策略** — 运行中应用免重启热替换，减少用户中断
3. **SHA-256 验证** — 主题包完整性校验

#### 技术实现

**核心架构 (Tauri v2 + Rust)**:
```
codexskin/
├── src-tauri/
│   ├── src/
│   │   ├── cdp/          # CDP 连接管理
│   │   ├── injection-js/ # JS 注入脚本
│   │   ├── injection/    # CSS 注入引擎
│   │   ├── process/      # 进程管理
│   │   └── storage/      # 配置持久化
│   ├── capabilities/     # Tauri 权限配置
│   └── icons/            # 应用图标
├── src/                  # 前端 (React/Vue)
└── public/               # 静态资源
```

**关键设计**:

1. **样式隔离机制** — 修复宠物窗口被错误注入壁纸的问题
   - 自动识别并排除 `avatar-overlay`（宠物页面）
   - 壁纸/主题仅对主页面生效
   - 保留宠物页面原生背景设置

2. **动态视觉特效**:
   - 呼吸动效（会呼吸的界面）
   - 图层微动（parallax layers）
   - 磨砂玻璃效果
   - 赛博朋克霓虹

3. **CDP 运行时渲染** — 不修改官方文件，仅内存注入
   - 注入通道仅对内（127.0.0.1）开放
   - 断开后自动恢复

4. **自动连接与断线重连** — 监控 Codex 状态

## 四、推荐方案

### P0: 实现 Deep Link 协议（来自 CodeDrobe）

**目标**: 实现 `agentskin://` 协议，支持从网页一键安装主题

**方案**:
1. 注册 `agentskin://` URL Scheme（Windows 注册表 + macOS Info.plist）
2. 协议格式: `agentskin://themes/apply?theme=<slug>&source=<url>`
3. 主进程 IPC 处理协议调用
4. 下载主题包 → 校验 SHA-256 → 应用

**收益**: 从 AgentSkin 官网/社区一键安装主题，降低用户操作门槛

**风险**: 需要签名应用才能注册协议；Windows/macOS 实现方式不同

### P0: 端口冲突自动顺延（来自 Dream Work Theme）

**目标**: 解决多应用同时运行时的端口冲突问题

**方案**:
1. 为每个适配器配置首选端口 + 端口范围
2. 启动前 TCP bind 检测端口可用性
3. 被占用时自动顺延到下一个可用端口
4. 记录实际使用端口用于后续注入

**收益**: 提升多应用并行场景下的鲁棒性

**风险**: 需要修改适配器启动逻辑；可能影响现有配置

### P1: 创建 AI Skill 自动安装（来自 cdredfox）

**目标**: 创建 SKILL.md 供 AI 助手自动完成主题安装

**方案**:
1. 编写 SKILL.md 描述安装流程
2. 包含平台检测、依赖检查、主题应用、验证
3. 支持 CodeBuddy / Claude / Cursor 等 AI 助手

**收益**: 用户可让 AI 助手自动完成 AgentSkin 主题安装

**风险**: 需要维护 SKILL.md 与实际功能同步

### P1: 右上角菜单注入（来自 cdredfox）

**目标**: 在目标应用内提供快速主题切换入口

**方案**:
1. 注入 🎨 按钮到目标应用 titlebar
2. 展开主题列表，点击即时切换
3. 支持自定义图片上传
4. 原生界面恢复

**收益**: 用户无需切换到 AgentSkin 即可切换主题

**风险**: 需要修改每个适配器的注入逻辑；可能与目标应用 UI 冲突

### P2: 桌面宠物系统（来自 Codress）

**目标**: 为 AgentSkin 添加桌面宠物功能

**方案**:
1. 创建独立的宠物窗口（透明、置顶、无交互）
2. 支持 Codex v2 宠物格式
3. 宠物与主题联动

**收益**: 差异化功能，提升用户粘性

**风险**: 增加复杂度；与"引擎非产品"定位冲突；需要额外资源
