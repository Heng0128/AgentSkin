## 2. 核心发现与行业趋势

### 趋势 1：macOS 原生应用 + Adapter 注册表模式成熟化
`quanzhankeji/cc-theme`（CC Theme）是目前最完整的 macOS 原生换肤应用：
- 版本化 `.cctheme` 包格式（ZIP 容器 + family.json + unified-theme.json + assets/）
- Adapter 注册表模式：mac-codex / mac-workbuddy / mac-doubao / mac-claude（暂停）
- 独立主题注册表仓库（cc-theme-themes）+ 机器可读 catalog.json（SHA-256 校验）
- 宠物系统（Xiaogou / Usagi / Tiko）作为独立功能层
- 正式 Adapter 在线更新 +  bundled fallback

### 趋势 2：Skill 安装成为主题分发的主流入口
`lanmengSakura/diana-codex-theme` 的 Skill 安装模式正在被社区广泛采用：
- `$skill-installer` + GitHub Skill 路径 → 自包含 SKILL.md
- 安装与挂载拆分为两条消息（确保 Skill 注册完成后再调用）
- "安装→配色部署→完整美术挂载"三阶段验证
- 公开包**不包含**任何运行器、watcher 或调试端口
- 完整挂载由用户自己的 Codex 在告知风险后生成本机实验适配器

### 趋势 3：安全边界设计从"功能驱动"转向"权限最小化"
`lanmengSakura/diana-codex-theme` 的 v0.2.2 → v0.2.9 演进路径开创了安全驱动的发布模式：
- **v0.2.2 移除**：所有 CDP watcher、计划任务、调试端口参数、@codedrobe/core 依赖

`Backtthefuture/qq2007theme` 验证了 CodeDrobe `.codedrobe-theme` 格式的生态黏性：

**核心创新**：

1. **Adapter 注册表模式**：bundled fallback Adapter + 在线正式更新 + 签名验证

3. **安全边界**：公开包不包含运行器、不修改应用签名、不持续开放端口
4. **宠物独立层**：Xiaogou / Usagi / Tiko 作为独立于主题的安装单元
5. **暂停机制**：paused-by-user 状态（win-* / mac-claude），保留源代码但排除出 CI/打包/发布
