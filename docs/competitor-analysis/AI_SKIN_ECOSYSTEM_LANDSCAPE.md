### 3.4 【第三轮·CDP 专项】CDP 基础层与通用注入 SDK

> 本轮**只聚焦 CDP（Chrome DevTools Protocol）本身**：不再局限于某一款 AI 客户端，而是补齐「所有 Electron/Chromium 桌面应用换肤」所共用的**协议层、注入器与调试 SDK**。这些是上层主题工具的底层地基，掌握后可对任意 Electron 应用（不限于 Codex/WorkBuddy）做运行时注入。均已核验（GitHub API 200）。

- **[tluyben/electron-inject](https://github.com/tluyben/electron-inject)** — Electron DevTools REPL：通过 CDP 向**任意正在运行的 Electron 应用**注入 JavaScript 的交互式 REPL，支持交互式执行、脚本文件、REST API 与命令历史；`--remote-debugging-port=9222` 连接，无需解包重打包，是理解「CDP 注入」机制的经典范本。
- **[ntoskrnl7/electron-cdp](https://github.com/ntoskrnl7/electron-cdp)** ⭐2 — `electron-cdp-utils`：简化 Electron 中 Chrome DevTools Protocol 使用的 TypeScript 库，封装 `MainSession`、自动附着 iframe/worker、SuperJSON 复杂类型序列化、执行上下文跟踪与生命周期管理，是构建自建换肤注入器的 SDK 底座。
- **[oussamaexe/electron-debugger](https://github.com/oussamaexe/electron-debugger)** ⭐1 — 面向 **AI 助手（MCP）** 的 Electron 调试服务器：通过 CDP 暴露 DOM 快照、元素样式、截图、点击/输入、React Fiber 树遍历、控制台日志、视觉回归等 15 个工具，让 Agent 直接「看懂并操控」任意 Electron 应用界面（`--remote-debugging-port=9222`）。
- **[ArthurLobopro/electron-css-injector](https://github.com/ArthurLobopro/electron-css-injector)** ⭐2 — 基于 Electron 内部 protocol API 的 CSS 注入包：在主进程与 preload 中引入即可在 `DOMContentLoaded` 时注入样式，是「把主题包打入应用」的轻量 SDK 层（区别于外部 CDP，属应用内集成方案）。

> 💡 **技术脉络小结**：上层主题工具（Codex-Dream-Skin、`dream-work-theme`、`@codedrobe/core`）本质都在做同一件事——`--remote-debugging-port` 启动 CDP → WebSocket 连渲染进程 → `Runtime.evaluate` / `Page.addScriptToEvaluateOnNewDocument` 注入 CSS+DOM 覆盖层 → 运行时生效、断开即还原。本节 3.4 的四个项目分别对应这条链路的 **REPL 调试器 / TS-SDK / AI-Agent 桥接 / 应用内 CSS 注入** 四种基础能力，可作为自制换肤引擎的参考实现。
