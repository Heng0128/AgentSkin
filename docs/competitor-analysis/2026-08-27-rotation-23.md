### 2.1 cdredfox/workbuddy-skin-studio — 图片驱动主题标杆

#### 基本信息
- **创建**: 2026-07-16
- **Stars**: 168 / Forks: 25

#### 技术实现

**架构设计**:
```
scripts/apply.command/.ps1 → 启动 WorkBuddy with --remote-debugging-port
                              ↓
src/cli.mjs → 连接 CDP → 注入 CSS + 菜单组件
                              ↓
右上角 🎨 菜单 → 即时切换主题
```

**核心文件结构**:
```
src/
├── cdp-client.mjs      # CDP WebSocket 客户端
├── cli.mjs             # CLI 入口
├── constants.mjs       # 常量定义
├── injector.mjs        # CSS/JS 注入器
├── skin-css.mjs        # 皮肤 CSS 生成
├── skin-menu.mjs       # 右上角菜单组件
├── theme-schema.mjs    # 主题 JSON Schema
└── theme-store.mjs     # 主题持久化
```

#### 技术亮点

##### 2.1.1 图片驱动主题生成

这是 workbuddy-skin-studio 最核心的差异化能力：

- **Canvas 自动取色** — 上传图片后，浏览器 Canvas 自动提取主色、辅色、面板底色、文字色
- **深浅色自动适配** — 根据 surface 明度（>140 为 light）自动切换 `data-vscode-theme-kind`
- **WebP 压缩** — 图片自动压缩为 WebP 格式，减少存储占用
- **localStorage 持久化** — 自定义主题保存在 localStorage，重启不丢失

**对比 AgentSkin**: AgentSkin 需要预定义 14-token 主题契约，而 workbuddy-skin-studio 支持任意图片即时生成主题，用户体验更直观。

##### 2.1.2 极简主题格式

```json
{
  "schemaVersion": 1,
  "id": "my-skin",
  "name": "My Skin",
  "hero": "hero.webp",
  "colors": {
    "accent": "#24C9D7",
    "secondary": "#EF8FD3",
    "surface": "#F7FBFF",
    "text": "#17344F"
  }
}
```

只有 4 个必填字段，图片 + 4 色即可构成完整主题。

##### 2.1.3 AI 自动化安装 SKILL.md

项目给 AI 助手提供了标准化的 SKILL.md，包含：
- 平台检测（macOS/Windows）
- 自动运行 apply 脚本
- 主题选择流程
- 验证与还原步骤

**对比 AgentSkin**: AgentSkin 缺少类似的 AI 自动化安装协议。

#### 与 AgentSkin 对比

| 维度 | workbuddy-skin-studio | AgentSkin |
|------|----------------------|-----------|
| 注入方式 | Loopback CDP | Loopback CDP |
| 主题生成 | Canvas 自动取色 | 预定义 14-token |
| 主题格式 | 极简 4+4 色 | 完整 14-token |
| 内置主题 | 10 个 | 15+ 个 |
| 切换方式 | 右上角 🎨 菜单 | Studio 内切换 |
| AI 安装 | SKILL.md 标准协议 | 无 |
| 平台支持 | macOS/Windows | macOS/Windows |

#### 可借鉴的设计

|--------|--------|--------|------|

### 2.2 tluyben/electron-inject — CDP 注入 REPL 经典实现

#### 基本信息
- **创建**: 2025-03-15
- **Stars**: 0 / Forks: 0
- **许可证**: 无
- **最后更新**: 2025-03-15（已停滞 17 个月）
- **状态**: 废弃

#### 技术实现

**架构设计**:
```
node server.js → 连接 Electron 应用 --remote-debugging-port=9222
                    ↓
交互式 REPL → Runtime.evaluate 执行 JS
                    ↓
REST API POST /execute → 程序化注入
```

**核心能力**:
1. **交互式 REPL** — 命令行直接执行 JS，支持历史记录
2. **脚本文件执行** — `--script` 参数加载 JS 文件
3. **REST API** — `POST /execute` 程序化调用
4. **命令历史** — 上下箭头导航

#### 技术亮点

##### 2.2.1 CDP 注入的教科书实现

这是理解 CDP 注入机制的最佳范本：

```javascript
// 连接 CDP WebSocket
const ws = new WebSocket('ws://localhost:9222/devtools/page/<id>');
ws.send({
  id: 1,
  method: 'Runtime.evaluate',
  params: { expression: 'document.title' }
});
```

##### 2.2.2 特殊命令系统

- `.exit` — 退出 REPL
- `.clear` — 清空控制台
- `.load <file>` — 加载并执行 JS 文件
- `.help` — 显示帮助

#### 与 AgentSkin 对比

| 维度 | electron-inject | AgentSkin |
|------|-----------------|-----------|
| 用途 | 调试/实验工具 | 生产级产品 |
| 持久性 | 临时注入 | 持久化 + 自动恢复 |
| 目标用户 | 开发者 | 终端用户 |
| 安全性 | 无防护 | epoch-manager + automation-lock |

#### 可借鉴的设计

| 设计点 | 可行性 | 优先级 | 说明 |
|--------|--------|--------|------|
| CDP 连接封装 | 低 | P3 | AgentSkin 已有成熟实现 |
| REST API 调用 | 低 | P3 | 不适合生产环境 |
| 调试工具 | 中 | P2 | 可参考用于开发调试模式 |

**结论**: 此项目已停滞 17 个月，技术实现较为基础，AgentSkin 已超越其能力。主要价值在于理解 CDP 注入的基本原理。

### 2.3 HeiGeAi/deepseek-harness-skin — 图片驱动主题生成系统

#### 基本信息
- **创建**: 2026-08-13
- **Stars**: 51 / Forks: 4
- **许可证**: MIT
- **最后更新**: 2026-08-23（4 天前）
- **平台**: Web UI (DSH)

#### 技术实现

**架构设计**:
```
用户上传图片 → 浏览器 Canvas 96px 采样取色
                    ↓
提取 4 色种（主色/副色/底色/文字色）
                    ↓
判断深浅色 → 自动调整蒙版浓度
                    ↓
WebP 压缩 → 存入 ~/.dsh/skins/
                    ↓
DSH Host 只读静态路由 → 前端展示
```

**核心文件结构**:
```
.
├── docs/               # 文档
├── patches/            # DSH 宿主集成补丁
├── scripts/            # 安装/卸载脚本
│   ├── install.sh      # 安装皮肤包
│   └── uninstall.sh    # 还原宿主
└── tree/               # 皮肤文件树
```

#### 技术亮点

##### 2.3.1 图片驱动主题生成

与 workbuddy-skin-studio 类似，但更强调**构建期校验**：

- **96px 采样取色** — 平衡性能与准确度
- **1920px WebP 重编码** — 限制长边，控制存储
- **内容哈希去重** — 同一张图只存一份
- **蒙版浓度自适应** — 根据画面明暗自动调整，保证文字可读性

##### 2.3.2 对比度保持推导

- 从图片提取的 4 色种自动推导完整配色
- 构建期校验 WCAG 对比度
- 不符合可读性要求时自动调整

##### 2.3.3 宿主集成方案

```bash
# 安装：备份 + 打补丁 + 写入皮肤
bash scripts/install.sh /path/to/deepseek-harness

# 卸载：还原备份
bash scripts/uninstall.sh /path/to/deepseek-harness
```

**注意**: 此方案需要修改 DSH 源码（打补丁），与 AgentSkin 的纯运行时注入不同。

#### 与 AgentSkin 对比

| 维度 | deepseek-harness-skin | AgentSkin |
|------|----------------------|-----------|
| 注入方式 | 源码补丁 + 构建 | 纯运行时 CDP |
| 主题生成 | Canvas 取色 + 对比度校验 | 预定义 14-token |
| 皮肤数量 | 21 套 + 自定义 | 15+ 套 |
| 持久化 | 构建时集成 | 运行时注入 |
| 可逆性 | uninstall.sh 还原 | 断开 CDP 即还原 |

#### 可借鉴的设计

## 三、行业趋势总结

### 3.1 图片驱动主题成为新范式

三个项目（workbuddy-skin-studio、deepseek-harness-skin、codress）都支持从图片自动生成主题，这已成为行业标准功能。

**核心流程**:
```
用户上传图片 → Canvas 采样取色 → 提取主色/辅色/底色/文字色
            → 判断深浅色 → 自动调整蒙版/对比度 → 生成完整主题
```

workbuddy-skin-studio 的右上角 🎨 菜单、deepseek-harness-skin 的设置面板皮肤区，都提供即时切换能力。

### 3.3 AI 自动化安装协议

workbuddy-skin-studio 的 SKILL.md 是创新点，为 AI 助手提供标准化安装流程。

### 3.4 纯运行时注入 vs 源码补丁

- **AgentSkin、workbuddy-skin-studio、codex-styler、codress** — 纯运行时 CDP 注入
- **deepseek-harness-skin** — 源码补丁 + 构建集成

纯运行时注入是主流趋势，源码补丁方案逐渐被淘汰。
