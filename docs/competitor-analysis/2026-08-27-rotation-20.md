### 2.2 Lumos-789/zcode-cdp — CDP 基础设施专家

**基本信息**
- 创建: 2026-08-01
- 语言: JavaScript
- 平台: macOS / Linux
- License: MIT
- 最新 Release: v0.2.0 (2026-08-14)

**技术亮点**
1. **Relay 架构** — TCP 中继 + 单常驻 backend，状态机 IDLE → ENSURING → ACTIVE → CLOSING
2. **端口租约系统** — 9223-9229 共 7 槽，原子 mkdir 抢锁 + leaseId ownership 校验
3. **三层看门狗** — 软(事件循环延迟) / CPU(busy-loop检测) / 硬(worker线程SIGKILL)
4. **Profile 隔离** — 每端口独立 profile + 不同卡通头像，多账号天然隔离
5. **MCP 集成** — 支持 MCP stdio 工具调用

**架构图**
```
Agent Clients → zcode-cdp-proxy (状态机懒加载) → lease 领端口 → 起 Chrome → @playwright/mcp
                     ↓
              zcode-cdp-relay (TCP中继)
                     ↓
              N 个已登录 Chrome (9223-9229)
```

**对 AgentSkin 的启示**
- 其端口租约系统可有效防止多 agent 并发时的端口冲突
- 三层看门狗设计对稳定性有很大提升
- 状态机懒加载模式可节省资源

**可借鉴点**
- 端口租约池设计（原子 mkdir + leaseId）
- 三层看门狗机制
- 状态机懒加载模式

## 四、推荐方案

### R1: 端口租约系统移植 (来自 zcode-cdp)

**可行性**: ⭐⭐⭐⭐⭐ 高
**优先级**: P0
**理由**: 
- 当前 AgentSkin 在多 agent 并发时可能遇到端口冲突
- zcode-cdp 的 mkdir 原子抢锁方案简单有效
- 可移植到我们的 ZCode 适配器

**实现思路**:
1. 创建 port-lease.ts 模块
2. 实现 mkdir 原子抢锁 + leaseId ownership
3. 端口池: 9223-9229 (7 槽)
4. 集成到 ZCode 适配器

### R2: 三层看门狗机制 (来自 zcode-cdp)

**可行性**: ⭐⭐⭐⭐ 高
**优先级**: P1
**理由**:
- 提高 CDP 连接稳定性
- 防止僵尸 Chrome 进程
- 防止 CPU busy-loop

**实现思路**:
1. 软看门狗: 事件循环延迟检测
2. CPU 看门狗: 主进程 CPU% 检测
3. 硬看门狗: worker 线程心跳检测

### R3: DOM Snapshot 功能 (来自 CodeDrobe/core)

**可行性**: ⭐⭐⭐ 中
**优先级**: P2
**理由**:
- 可用于 Studio 页面的主题制作辅助
- 只读操作，不影响目标应用
- 但需要额外 UI 展示

**实现思路**:
1. 创建 dom-snapshot.ts 模块
2. 记录元素关系、computed-style、selector 候选
3. 导出 JSON 供 AI 辅助主题制作
