# AgentSkin 桌面应用 — 前端 UI 设计全面分析报告

> 生成日期：2026-08-09  
> AgentSkin 版本：v1.0.0  
> 技术栈：Electron + React 19 + Zustand v5 + Tailwind CSS 4

---

## 一、项目概览

**AgentSkin** 是一款 **AI Agent 视觉定制引擎**桌面应用，基于 Electron + React 19 + Zustand v5 + Tailwind CSS 4 构建。

### 技术栈
- **框架**: React 19 + TypeScript
- **状态管理**: Zustand v5 (多 Store 架构)
- **样式**: Tailwind CSS 4 + CSS 变量主题系统
- **图标**: HugeIcons + Lucide React
- **字体**: Space Grotesk (品牌) + IBM Plex Mono (标签) + 系统字体 (正文)
- **UI组件**: Radix UI + shadcn/ui 风格封装

### 设计语言
- **风格**: （历史）Swiss / International Typographic Style
- **圆角**: 全域 2px 方角，锐利几何
- **色彩**: 仅主色红色用于强调，中性灰阶主导
- **字体层级**: Space Grotesk (品牌) / Mono (标签) / 系统字体 (正文)

## 八、跨组件设计一致性规则

| 特征 | 表现 |
|------|------|
| **圆角** | 全部使用 `rounded-[2px]` 或 `rounded-[22%]`，仅在品牌/App icon 使用更大圆角 |
| **字体** | 数据密集区（表格、卡片）一律 `font-mono text-[9px~11px]`，内容区 `text-xs/text-sm` |
| **边框** | 统一使用 `border-border`，空状态用 `border-dashed border-border/40` |
| **阴影** | 工具面板用 `shadow-xl` 硬阴影；环境卡片用 `shadow-lg shadow-primary/5` 品牌光 |
| **动效** | 环境区丰富的动画（aurora + float + ping）；工具面板几乎无动画 |
| **深度层级** | 通过 `bg-card2` / `bg-muted/20` / `bg-white/[0.06]` 多层次而非仅靠颜色 |
| **无障碍** | `aria-hidden` 装饰性图层；`role="img"` Logo/图标；ErrorBoundary 标题层级 |
