## 九、移植建议

1. **优先 CodeDrobe 主题商店**：一个包适配多应用（Codex/WorkBuddy/QoderWork/TRAE），格式统一（`.codedrobe-theme`），可导入研究。
2. **Codex 主题源最丰富**：`awesome-codex-themes` 目录 + 本地 81 个包 + Dream Skin 主题集，够移植很久。
3. **TRAE/Qoder/WorkBuddy/ZCode 豆包**：多为 Skill 或专用工具，主题包较少，可先从 CodeDrobe 商店获取。
4. **筛选标准**：不要求高星，只要主题包完整（有 theme.json/theme.css/背景图）即可收录。
