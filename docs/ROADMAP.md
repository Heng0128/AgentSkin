## 禁止清单（与 P0/P1 同等约束力）

1. 禁止新增适配器，除非同时满足"用户基数大"且"无原生主题能力"。
2. 禁止 Studio 新增创作类功能（减重完成前）。
3. 禁止自建内容 CDN、账号系统、服务端。
4. 禁止重构注入架构（当前架构良好）。
5. 禁止新增 UI 页面（六页封顶；Workspace 做实或并入）。
6. 禁止再写一次性提案文档——需求直接进本文件的 P0/P1。
