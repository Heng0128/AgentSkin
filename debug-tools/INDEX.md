# debug-tools — 一次性探针 / 调试脚本

## 用途
归档 AgentSkin 各 Agent（codex / doubao / workbuddy / traework / qoderwork / zcode）
排查过程中产生的一次性探针、调试、临时修复脚本。

> **重要约定：本目录属于调试资产，禁止随意删除。**
> 后续进行主题制作、移植适配、升级排障时，这些脚本经常会被复用来重新定位
> 渲染不一致、CDP 注入、持久化等问题。

## 结构

| 前缀 | 内容 |
|------|------|
| `probe-*` | 渲染/CSS/CDP 探针，用于核对目标应用实际生效样式 |
| `apply-*` | 针对单 Agent 的临时主题注入/修复脚本 |
| `cleanup-*` | 清理类探针残留脚本 |
| `debug-*` | 一次性复现某个问题流的调试脚本 |
| `_probe-*` | 内部临时探针（下划线前缀，代表性命名，同属调试资产） |
| `probe-trm-cdp.mjs` | 根目录迁入的 CDP 结构探针 |

## 与其他目录关系

- 深度与 `scripts/` 同级（均位于仓库根部一级子目录），因此脚本内 `../src/...` 引用可直接指向仓库 `src/`。
- 探针截图类产物（如 `codex-probe.png`）统一输出到 `assets/probe-shots/`（本地裁剪产物，不入库）。
- baseline/探针 JSON 快照保留在 `agents-run-now/`。

## 约定

1. **请勿删除本目录下任何文件**——它们是从根目录或 `scripts/` 迁入的调试资产，未来排查会复用。
2. 新的一次性探针脚本建议直接放入本目录，避免再次散落到根目录或 `scripts/`。
3. 若脚本依赖仓库 `src/`，保持 `../src/...` 相对结构（与 `scripts/` 同级，无需多级 `..`）。
