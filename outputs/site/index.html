核心功能

一个平台，管住所有 AI 编码工具的皮肤

从主题安装到跨 Agent 同步，AgentSkin 把零散的外观管理收到一处。

统一主题管理

集中浏览、安装、启停所有已适配 Agent 的主题，状态一目了然，不再在各个编辑器设置里来回切换。

• 已安装 / 启用 / 推荐 三态标记 • 本地主题库与导入导出

实时预览与一键应用

改一处，目标 Agent 立刻换肤。内置实时预览窗，挑主题时就能看到在你编辑器里的真实效果。

• 无需重启编辑器即生效 • 暗色 / 亮色双模式自动跟随

跨 Agent 主题同步

同一套配色，自动映射到不同 Agent 的 token 体系——workbuddy 的 --cb-*、traework 的 --vscode-* 都不在话下。

• 多套 token 体系自动适配 • 实验性 Agent 一键启用
